## Правки для режима Viber Business / SMS

Все изменения касаются только режима `viber` и не затрагивают другие каналы.

### 1. Заголовок «Кнопка»
В `EditorPanel.tsx`, секция Inline кнопки: для Viber лейбл `Кнопка (одна)` → `Кнопка`.

### 2. Лейбл SMS-фолбэка
`SMS-сообщение (фолбэк)` → `SMS-сообщение` (оставляем иконку `MessageSquare`).

### 3. Урезанная панель форматирования
В тулбаре форматирования для Viber оставить только: **Жирный**, **Курсив**, **Зачёркнутый**, **Моноширинный** (новая кнопка с `Code` иконкой, оборачивает в ` ``` … ``` `). Убрать: Подчёркнутый, Ссылка, Цитата (Заголовок и так только для MAX).

Также убрать кнопку «Цитата» из общего набора — если канал Viber. В `insertFormatting` добавить ветку `mono` → `` `${text}` `` (одинарные бэктики; для блока — тройные. Используем одинарные как inline-код, согласно ТЗ ` ```моноширинный``` ` — берём тройные, чтобы соответствовать примеру пользователя).

### 4. Порядок секций в редакторе для Viber
Перестроить рендер `EditorPanel`, когда `isViber === true`:
1. Маршрут отправки (select)
2. Медиа (одна фотография)
3. Текст сообщения Viber
4. Кнопка (одна)
5. SMS-сообщение — **рендерить только если** `viberRoute` содержит `sms` (т.е. `viber(60)-sms`, `viber(30)-sms`, `sms-only`). Для `viber-only` секцию скрываем и очищать значение не нужно (оно просто не уйдёт в JSON — но добавим: если маршрут `viber-only`, не включать `param_sms` в JSON через build — оставим как есть, т.к. поле скрыто пользователю).

Валидация: если маршрут требует SMS и `smsText` пустой — подсветить textarea красной рамкой и показать сообщение под ним «Укажите текст SMS для выбранного маршрута» (по аналогии с `mediaUrlMissing`).

Реализация: в текущем JSX блок «Viber: SMS fallback + route» вынести вверх (перед Media), разделить порядок и обернуть SMS-секцию в `{routeNeedsSms && (...)}`. Маршрут переместить первым.

### 5. Убрать «Кодировка» из подписи SMS
Текст `Кодировка: GSM (латиница)` → `Латиница` или `Кириллица` (без слова «Кодировка» и без пометки GSM/UCS2). Логика определения остаётся через `smsParts(...).encoding`.

### 6. Заблокировать «Настройки» в JsonPanel
В `JsonPanel.tsx` на кнопке настроек добавить `disabled={isViber}` плюс затемнённый стиль и тултип «Недоступно для Viber Business / SMS». Уже скрытый/недоступный «Тестировать» оставить как есть.

### Файлы
- `src/components/builder/EditorPanel.tsx` — пункты 1–5 (тулбар, порядок, лейблы, валидация, подпись SMS).
- `src/components/builder/JsonPanel.tsx` — пункт 6 (disabled настроек для Viber).

Никаких изменений в `message-builder.ts`, контексте или JSON-схеме не требуется — структура `param_sms` / `route` / `image_url` / `btn_*` уже правильная.
